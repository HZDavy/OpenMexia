功能特性Features

为桌面而生的米家控制台A Mi Home console built for the desktop

01

米家扫码登录QR code sign-in

用米家 App 扫码即可，与官方一致的登录流程，无需输入账号密码。Scan with the Mi Home app — the same official login flow, no password typing.

02

瀑布流设备卡片Masonry device cards

每张卡片按自身高度排列成瀑布流，支持拖动排序与双击收折，列数随窗口宽度自适应。Cards stack in a true masonry layout. Drag to reorder, double-click to collapse, columns adapt to window width.

03

状态实时同步Live status sync

开关状态、温湿度、功率电量自动刷新，设备上下线即时可见。Power state, temperature, humidity and energy update automatically — online status at a glance.

04

丰富的设备控制Rich device controls

灯光亮度与色温、风扇风速 / 模式 / 扫风、空调目标温度、净饮机水温，规格按型号自动适配。Brightness & color temperature, fan speed / mode / oscillation, AC target temp, water temp — specs adapt per model.

05

常驻置顶小窗Always-on-top widget

小窗常驻桌面一角并置顶显示，自动记住窗口位置、大小和所有设置。A compact window pinned to a corner, always on top. Remembers position, size and every setting.

06

托盘菜单与开机自启Tray menu & auto-start

系统托盘提供全部常用操作，可设置开机自动启动，登录后设备状态立刻就位。All common actions live in the system tray. Enable launch at login and status is ready instantly.

07

两种全屏模式Two fullscreen modes

普通全屏保留任务栏；覆盖全屏完全置顶铺满整块屏幕，适合信息墙场景。Normal fullscreen keeps the taskbar; cover mode fills the screen on top — great for a dashboard wall.

08

一键发送到副屏Send to second screen

多显示器环境下，一键把小组件移到下一块屏幕，自动居中并防止裁切。On multi-monitor setups, move the widget to the next display with one click — centered and never clipped.

四步上手How it works

30 秒，从下载到用上Up and running in 30 seconds

1

下载安装Download & install

在 Releases 下载安装包，可自选安装目录，无需额外运行环境。Grab the installer from Releases. Pick any install folder — no runtime required.

2

扫码登录Scan to sign in

打开应用后用米家 App 扫码授权，登录凭据仅保存在本机。Open the app and authorize with Mi Home QR scan. Credentials are stored only on this PC.

3

设备自动成卡Cards appear

账号下的设备自动拉取，按 MIoT 规格生成控制卡片并开始同步状态。Your devices are fetched automatically and rendered as MIoT-spec control cards with live status.

4

拖到顺手的位置Place & control

拖动卡片排序、收折不常用的设备，把小窗钉在桌面一角随手控制。Reorder cards, collapse what you rarely use, pin the window to a corner and take control.

常见问题FAQ

下载前，你可能想知道Before you download

SmartScreen 拦截怎么办？SmartScreen warning?

个人开源项目暂未购买代码签名证书。点击「更多信息」→「仍要运行」即可，软件完全开源可审计。The app is unsigned for now. Click “More info” → “Run anyway”. The source is fully open and auditable.

米家账号安全吗？Is my account safe?

走米家官方扫码登录，凭据仅保存在本机应用数据目录，不经过任何第三方服务器。It uses the official Mi Home QR login. Credentials stay in the local app-data folder and never touch third-party servers.

支持哪些设备？Which devices work?

符合 MIoT 规范的设备按型号自动适配控制项；网关、温度计等只读设备仅展示状态。MIoT-compliant devices get controls auto-matched by model. Read-only devices like gateways and thermometers show status only.

软件收费吗？Is it free?

完全免费且开源，没有内购、广告与统计。你也可以自行从源码构建。Completely free and open source — no in-app purchases, ads or tracking. Build it yourself from source.

为什么是 AGPL 协议？Why AGPL?

项目依赖 GPL-3.0+ 的开源组件，作为衍生作品须以兼容协议发布，详见仓库 LICENSE。It depends on a GPL-3.0+ component, so the derivative work ships under a compatible license. See LICENSE in the repo.

支持 macOS 吗？What about macOS?

当前仅发布 Windows x64 安装包。代码基于 Electron，欢迎在 GitHub 上参与移植。Only the Windows x64 build is published today. It is Electron-based — ports are welcome on GitHub.
